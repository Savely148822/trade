# MOEX-портфель на всю жизнь

Локальное приложение для постепенного сбора долгосрочного портфеля на Московской
бирже. Сценарий простой: вы пополняете рублевый баланс, а бот говорит, какой
инструмент купить следующим.

Целевая логика сборки:

1. Сначала набираем 70% портфеля в голубых фишках.
2. Потом набираем 20% в рублевых облигациях/ОФЗ.
3. Потом добавляем 10% потенциально быстрорастущих компаний.

Если баланс маленький и сразу купить все нельзя, приложение не пытается собрать
идеальный портфель одним действием. Оно выбирает следующий этап и предлагает
покупку, которая помещается в свободный рублевый баланс с учетом лота.

> Подсказки являются механической моделью для ведения структуры портфеля, а не
> индивидуальной инвестиционной рекомендацией.

## Что умеет MVP

- Работает локально на компьютере через браузер.
- Хранит данные в файле `data/portfolio.json`.
- Поддерживает только рубли и инструменты Московской биржи из встроенного
  watchlist.
- Позволяет внести деньги на свободный баланс.
- Не дает записать покупку, если на балансе недостаточно рублей.
- После покупки списывает рубли с баланса.
- После продажи возвращает рубли на баланс.
- Показывает:
  - свободный баланс;
  - стоимость позиций;
  - стоимость активов вместе с кешем;
  - прибыль/убыток по позициям;
  - прогресс к структуре 70/20/10.
- Подсказывает, что купить сейчас:
  - тикер;
  - название;
  - этап сборки;
  - размер лота;
  - примерную цену и сумму покупки.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте в браузере:

```text
http://localhost:3000
```

## Как пользоваться

1. В блоке `Пополнить баланс` укажите сумму в рублях.
2. Посмотрите блок `Что купить сейчас`.
3. Купите предложенный инструмент в своем брокерском приложении.
4. В блоке `Записать исполненную сделку` внесите фактическую цену и количество.
5. Повторяйте при новых пополнениях.

## Рыночные данные

Для российских акций приложение пробует получать котировки через Yahoo Finance
с MOEX-суффиксом, например `SBER.ME`. Для облигаций и инструментов, где
котировка недоступна, используется ориентир из watchlist или средняя цена
покупки.

## Ограничения

- Встроенный список инструментов — стартовый. Его можно расширять в
  `src/portfolio.js`.
- Комиссии, налоги, купоны, дивиденды и НКД пока не учитываются.
- Для облигаций используется упрощенная модель цены и лота.
- Приложение не подключается к брокеру и не выставляет заявки само.
