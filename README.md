# MOEX-портфель на всю жизнь

Локальное приложение для постепенного сбора долгосрочного портфеля на Московской
бирже. Сценарий: вы вручную отмечаете, что внесли рубли на брокерский счет, а бот анализирует рынок через
публичный API Мосбиржи и предлагает, что докупить или что сократить.

Целевая логика портфеля:

1. 70% — голубые фишки.
2. 20% — облигации/ОФЗ.
3. 10% — потенциально быстрорастущие компании.

Если указанная сумма небольшая, бот не пытается купить все сразу. Он выбирает текущий
этап сборки, проверяет доступный кеш с учетом комиссии брокера и предлагает
следующий доступный лот.

> Подсказки являются механической моделью для дисциплины портфеля, а не
> индивидуальной инвестиционной рекомендацией.

## Источник данных

Вместо Yahoo используется официальный публичный API Московской биржи:

```text
https://iss.moex.com/iss/
```

Приложение использует MOEX ISS для:

- спецификаций инструментов;
- текущих marketdata;
- свечей истории;
- состава индекса голубых фишек MOEXBC.

Примеры endpoint-ов:

```text
/iss/engines/stock/markets/shares/boards/TQBR/securities/SBER.json
/iss/engines/stock/markets/bonds/boards/TQOB/securities/SU26243RMFS4.json
/iss/statistics/engines/stock/markets/index/analytics/MOEXBC/tickers.json
```

## Как бот выбирает инструмент

Выбор больше не является простым порядком из списка. Бот строит скоринг:

- определяет класс инструмента:
  - облигации — по рынку/типу бумаги MOEX;
  - голубые фишки — по индексу MOEXBC, ликвидности и капитализации;
  - остальные акции — в ростовую часть;
- учитывает целевую структуру 70/20/10;
- проверяет доступность лота с учетом комиссии;
- оценивает рынок:
  - дневной оборот;
  - спред;
  - уровень листинга;
  - положение цены в 52-недельном диапазоне;
  - динамику за 20 и 60 дней;
  - признаки перекупленности;
  - для облигаций — доходность, дюрацию, купон и НКД.

В результате бот показывает:

- `Buy score` — насколько бумага подходит для докупки сейчас;
- `Перекупленность` — насколько покупка выглядит перегретой;
- причины выбора;
- риски;
- возможные идеи на продажу/сокращение.

## Ежедневный анализ

Приложение формирует ежедневный отчет, который можно показывать в веб-интерфейсе
и позже отправлять в VK-бота по расписанию. Отчет включает:

- краткий итог по рынку MOEX из отслеживаемой вселенной бумаг;
- сколько бумаг выросло и сколько упало;
- лидеров роста и падения;
- дневной вклад каждой позиции в изменение портфеля;
- объяснение, почему портфель вырос или упал;
- главные действия на сегодня: что докупить, что сократить, какие есть ИИС-3 напоминания.

Причины роста/падения строятся из текущего движения цены, ликвидности, buy score,
перекупленности и уже рассчитанных сигналов портфеля.

## ИИС-3

Приложение ведет портфель как ИИС-3 по умолчанию. В настройках можно указать:

- дату открытия ИИС-3;
- годы, за которые вы уже получили вычет;
- ставку НДФЛ для оценки размера возврата;
- комиссию брокера.

Бот считает взносы по годам и напоминает, когда наступает следующий год и можно
подать заявление на вычет по прошлогодним взносам. Оценка вычета ограничена
базой 400 000 ₽ в год и указанной ставкой НДФЛ.

Для вывода средств есть отдельный блок: вводите желаемую сумму, а бот строит
план продаж. Алгоритм сначала учитывает свободный кеш, затем сортирует бумаги по
сочетанию факторов:

- налоговый риск на ИИС-3;
- есть ли прибыль или убыток по позиции;
- признаки перекупленности;
- низкий buy score;
- превышение целевой доли категории;
- комиссия брокера и размер лота.

Важно: для ИИС-3, открытых в 2024-2026 годах, минимальный срок счета обычно
составляет 5 лет для сохранения вычетов на взнос. Освобождение положительного
финансового результата нужно проверять отдельно по актуальным правилам и
позиции брокера как налогового агента; в приложении это отражено как налоговый
риск, а не гарантия отсутствия налога.

## Комиссия брокера

По умолчанию используется комиссия `0,06%`.

Ее можно изменить прямо в интерфейсе в блоке `Настройки брокера`. Комиссия
учитывается:

- при проверке, хватает ли рублей на покупку;
- при расчетном уменьшении доступного кэша после покупки;
- при зачислении денег после продажи;
- в себестоимости позиции.

## Сервис и пользователи

Приложение теперь работает как multi-user сервис:

- пользователь регистрируется по email и паролю;
- пароль хранится как scrypt-хеш с солью;
- вход работает через HttpOnly cookie-сессию;
- у каждого пользователя отдельные ручные отметки внесения средств, сделки, настройки ИИС-3, комиссия и история;
- API портфеля, сделок, вывода и настроек требуют авторизации.

Данные MVP хранятся в локальной SQLite-базе:

```text
data/service.sqlite
```

Для VPS важно задать секрет сессий через переменную окружения:

```bash
APP_SECRET=very-long-random-secret npm start
```

Для настоящего публичного запуска следующим шагом лучше перейти с локального SQLite на PostgreSQL, добавить восстановление пароля, rate limiting, резервные копии и HTTPS через nginx.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте:

```text
http://localhost:3000

После открытия зарегистрируйте пользователя или войдите в существующий аккаунт.
```

## Важное про ручные данные

Сервис не видит брокерский счет и не подключается к API брокера. Когда вы указываете внесение средств, это ручной сигнал: “я внес или планирую внести N рублей у брокера”. Все рекомендации строятся на этих ручных данных и записанных вами сделках.

## Как пользоваться

1. Укажите комиссию брокера, если она отличается от `0,06%`.
2. Укажите ручной сигнал о внесении средств на брокерский счет.
3. Посмотрите блок `Что сделать сейчас`.
4. Купите предложенный инструмент в брокерском приложении.
5. Запишите фактическую сделку в интерфейсе.
6. Повторяйте при новых внесениях средств у брокера.

## Ограничения MVP

- Приложение не подключается к брокеру, ФНС и не выставляет заявки само.
- Фундаментальные мультипликаторы и отчетность пока не подключены.
- Скоринг основан на публичных рыночных данных MOEX ISS.
- Для облигаций расчет НКД/цены упрощен и служит ориентиром.
- Дивиденды, купоны, налоги и полноценный учет реализованной прибыли пока не
  учитываются.
