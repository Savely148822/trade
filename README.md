# Портфель на всю жизнь

Локальное приложение-помощник для долгосрочного инвестиционного портфеля.
Идея: вы запускаете интерфейс на своем компьютере, записываете покупки и
продажи, а приложение хранит историю, подтягивает рыночные цены, показывает
стоимость портфеля, прибыль/убыток по позициям и подсказывает ребаланс.

Целевая структура портфеля:

- 70% — голубые фишки;
- 20% — облигации;
- 10% — потенциально быстрорастущие компании.

> Важно: рекомендации в приложении являются механическими подсказками по
> структуре портфеля и не являются индивидуальной инвестиционной рекомендацией.

## Возможности

- Локальный веб-интерфейс для компьютера.
- Добавление сделок покупки и продажи: тикер, категория, количество, цена,
  валюта, дата и заметка.
- Хранение портфеля в `data/portfolio.json` на вашем компьютере.
- Получение котировок через локальный сервер с Yahoo Finance chart API.
- Расчет:
  - текущей стоимости портфеля;
  - вложенной суммы;
  - нереализованной прибыли/убытка;
  - прибыли/убытка по каждой позиции;
  - отклонения от целевой структуры 70/20/10.
- Автоматические подсказки:
  - что докупить, если категория ниже целевого веса;
  - что сократить, если категория выше целевого веса;
  - какие инструменты рассмотреть из встроенного watchlist.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

После запуска откройте:

```text
http://localhost:3000
```

## Как пользоваться

1. Откройте интерфейс в браузере.
2. В форме слева выберите тип операции: `Купил` или `Продал`.
3. Укажите тикер, категорию, количество, цену сделки, валюту и дату.
4. Нажмите `Запомнить сделку`.
5. Нажмите `Обновить цены рынка`, чтобы подтянуть актуальные котировки.
6. Смотрите позиции, прибыль/убыток, структуру портфеля и рекомендации.

## Рыночные данные

Приложение использует публичный endpoint Yahoo Finance:

```text
https://query1.finance.yahoo.com/v8/finance/chart/{ticker}
```

Если котировка временно недоступна, приложение продолжит показывать позицию по
последней сохраненной цене или по средней цене покупки.

## Ограничения MVP

- Суммы по портфелю считаются корректно, когда позиции ведутся в одной базовой
  валюте. Если в портфеле смешаны валюты, приложение покажет предупреждение.
- Налоги, комиссии, дивиденды, купоны и FX-конвертация пока не учитываются.
- Watchlist зашит в коде и служит стартовым списком кандидатов для докупки.
