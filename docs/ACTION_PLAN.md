# План: движок приращения капитала (РФ)

## Выбор площадки

| Роль | Выбор | Почему |
|------|--------|--------|
| **Брокер (исполнение)** | **Финам** | Зрелый [Trade API](https://api.finam.ru/) (REST/gRPC), MOEX, заявлена поддержка алготрейдинга |
| **Резерв / ручной контроль** | Т-Инвестиции | Удобное приложение; API подключим позже при необходимости |
| **Данные до открытия счёта** | [MOEX ISS](https://iss.moex.com/iss/reference/) | Бесплатные котировки и свечи для paper-режима |
| **Крипта (фаза 5)** | Отдельная биржа | Не смешиваем с брокерским счётом на старте |

**Не используем как основу:** Interactive Brokers для нового счёта с паспортом РФ (высокий риск закрытия).

---

## Архитектура счёта (без цели «к 50 годам»)

- **Core ~80%** — БПИФ + ликвидные акции MOEX + ОФЗ-фонды; дневной таймфрейм; реинвест 100%.
- **Satellite ~20%** — импульс на MOEX (фаза 3–4); крипта — фаза 5.

Правила core: momentum + тренд, сливки при перегреве, выход при сломе тренда, фильтр ликвидности.  
Правила satellite: breakout + ATR-стоп, monthly loss cap.

## Фазы внедрения

### Фаза 0 — Подготовка (вы вручную, 1–3 дня)

- [ ] Открыть брокерский счёт **Финам** (можно начать с демо/минимального пополнения).
- [ ] В [личном кабинете Trade API](https://tradeapi.finam.ru/) получить **токен** (пока не вставлять в git).
- [ ] Решить: **ИИС тип Б** или обычный брокерский (для долгого core часто выгоден ИИС Б — уточнить у брокера/ФНС).
- [ ] Скопировать `.env.example` → `.env`, оставить `PAPER_TRADING=true`.

### Фаза 1 — Paper-бот (код в репозитории) ✅ старт

- [x] Каркас: core/satellite, MOEX ISS, paper-портфель.
- [ ] Запуск: `python -m bot` — анализ и виртуальные сделки.
- [ ] 2–4 недели смотреть логи: сигналы, просадку paper, список сделок.

### Фаза 2 — Подключение Finam API

- [ ] В `.env`: `FINAM_TOKEN`, `PAPER_TRADING=false` (или гибрид: данные live, сделки paper).
- [ ] Реализовать live-ордера в `bot/brokers/finam.py` (сейчас — заглушка с NotImplemented).
- [ ] Прогон на **минимальных** суммах.

### Фаза 3 — Расширение вселенной

- [ ] Скринер ликвидности MOEX (авто-отбор топ-N по обороту).
- [ ] Подключить БПИФ «мировых» индексов (TMOS, TEMS, TEUS и т.д.) в core whitelist.

### Фаза 4 — Satellite MOEX

- [ ] Импульсные акции из топ-ликвидности, лимит убытка satellite за месяц.

### Фаза 5 — Крипта (опционально)

- [ ] Отдельный адаптер CCXT, не более 20% equity, свой loss cap.

## Чеклист перед live

- Paper equity curve без «обвала» > заданного лимита.
- Понятны комиссии Финам на ваших инструментах.
- В `.env` заданы `MAX_DRAWDOWN_PCT`, `CORE_WEIGHT`, `SATELLITE_WEIGHT`.
- Токен API только в `.env`, не в репозитории.
